# Agents-Dust
Fichiers de configuration .yml des agents créés dans Dust :

* Aide à l’apprentissage en IA (_Tuteur_IA_agent)
* Chaînage de deux agents (Meeting-Workflow_agent) pour structurer l'avant et l'après-réunion (PreMeetBrief_agent, Follow-Up_agent)
* Agent de routage des requêtes (Routeur_question_agent)
* Agent connecté aux serveurs MCP (AnnuaireRH_agent)
